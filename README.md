<h3 align="center">📂 Projects</h3>

#### 🌍 Trip en Arvor
**Description**:  
Trip en Arvor is a web platform developed to promote activities, restaurants, and events in Brittany.  
The project allows professionals to post their advertisements and users to leave reviews or explore offers in detail.

**Key Features**:  
- Post and manage advertisements (restaurants, activities, events, etc.).  
- User reviews with posting and deletion options.  
- Enable or disable advertisements.  

**Methodology**:  
- Agile development using **Scrum**.  
- Intensive user testing during the development phase.  

**Achievements**:  
- Fully functional MVP delivered on time.  
- Positive client feedback for user experience and features.

**Technologies Used**:  
- **Frontend**: HTML5, CSS3, JavaScript.  
- **Backend**: PHP, PostgreSQL.
